# 모아 초대 페이지

공유 메시지의 초대 링크(`https://hyyyyjin.github.io/moa-invite/?code=XXXX`)가 여는 정적 페이지입니다.
카카오톡 등은 `og.png`로 썸네일 카드를 만듭니다. 초대한 사람 이름은 이미지에 넣지 않고 공유 메시지 글자에만 넣습니다.

- `index.html`: 초대 코드 표시, 앱 열기(`sobok://join?code=`), 코드 복사
- `og.png`: 1200×630 공통 썸네일
- `icon.png`, `favicon.png`: 앱 아이콘

GitHub Pages로 배포하는 별도 공개 저장소(`hyyyyjin/moa-invite`)에 이 폴더 내용을 올립니다.
